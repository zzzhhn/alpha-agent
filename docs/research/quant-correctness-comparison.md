# 量化修正：同一输入的改前／改后对照

这组离线样本固定了 32 个日期、12 只合成股票的因子值和收盘价。表中的仓位、收益和净值都由实际回测内核计算，Zoo 使用同一组因子及前瞻收益独立构建策略序列。基线为 `abe2aeb5eac465e145a7e25edb2c39e428eeac8e`；改后为本次工作树。不是实盘数据、历史收益估计或投资判断。

这次修正没有改变手续费公式。样本改后的首日开仓总换手为 2，10 bps 费率因此对应 20 bps 组合收益差。新闻窗口等输入未用于样本；可选的财报遮罩仍只把命中股票的权重置零，不补仓。分篮按有限值排序，单边数量为 `floor(N × 比例)`，最少一只，完整等值截面不建仓。Zoo 将没有可观察持仓收益的日期排除出相关性样本，并对每一对序列分别取共同日期。Screener 保留部分覆盖的合成方式：至少一个非零权重因子得分可用才有资格，其余缺失项贡献仍为零。
