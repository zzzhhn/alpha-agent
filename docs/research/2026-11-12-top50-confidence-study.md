# Top50 推荐可信度离线研究（2026-11-12）

依据：[方法论深度研究](2026-11-12-methodology-deep-research.md)、[冻结协议及v1.1.0](2026-11-11-quant-p0-baseline-protocol.md)。

研究版本：`top50-exploratory-v0.1-20261112`。状态：**证据不足，未授权任何线上改动**。全部数字来自本地实际计算；没有网络、生产库或 LLM 调用。本文只含聚合结果。

## 判断与边界

- **已确认（样本内计算）**：没有得到可信的 Top50 盈利优势。5 日可用标签诊断中，Top50 相对 eligible 等权平均少赚约 0.493 个百分点；全臂价格完整后为 −0.265 个百分点，区间跨零。前者不能当作真实可成交组合业绩。
- **已确认（样本内计算）**：confidence、agreement 未呈现可靠、单调的正向收益校准；coverage 根本没有可用观测。当前字段不能解释为“盈利概率”。
- **推断**：较值得预注册的是 12–1 动量替代因子和持有带，而不是直接提高某个赢家权重。动量在验证期有正 IC，但历史检查期较长期限失效；持有带降低名单变化，却尚未改善收益。
- **未知**：任何提案对未来 Top50 盈利概率的净提升、因果贡献、可执行现金净值、以及新恢复预设的前瞻效果。

## 数据与方法

**已确认**：71 次 complete 运行，7 次日期不是 XNYS session（包含周末和休市日），留下 64 个可定义 D 收盘的运行；有效日期区间 2026-06-22 至 2026-11-11，共 101 个自然交易日，不能把 64 次运行叫作 101 次完整决策。没有同日重复运行。未将非交易日移到别的 D。快信号只有 54 个观测日期且存在间断，不将其视为完整发布历史。

执行统一为 D 收盘决策、D+1 的 XNYS 收盘入场、D+1+h 收盘退出。逐期收益不是年化收益，不把重叠标签复利成 NAV。价格沿完整日历重建；缺入场、退出或中间任意收盘都保留为缺失，不用“下一条有价格记录”替代交易日。PARA 在 2025-08-06 后始终排除。生产价格共发现 10 个单日绝对跳变 >35% 的单元、9 个标的；默认屏蔽决策至退出期间受影响的标签，完整报告不屏蔽的敏感性。

成本为单边总 10/15/20/30bps。独立买入持有标签按 `gross − f − f*(1+gross)` 扣买卖成本，卖出按退出名义金额收费；同 EW、SPY 比较都对基准收取相同入退出成本。Top20/Top50/剩余组为名单等权标签实验，不是现有 L2 整股/现金执行重放；Q4 固定每个槽位 2%，不足 50 留现金，故不能直接把 Q1 和 Q4 的绝对收益当成同一臂。

排序使用保存的 immutable `rank`，不以今日参数重新生成历史发布；负 rank IC 才是好方向。报告同时保存 `score_ic = corr(-rank, forward)` 和原始 composite IC。对同日全部股票减相同 EW 或 SPY，不改变 Spearman IC。实际 effective 权重另与静态先验比较，不能把 0.30 先验误说成每次实际因子权重。

**已确认（完整性审计）**：所有 complete 行的 coverage 均空；dimension_scores 仅 239 行非空，来自尚无可成熟前瞻标签的尾部快照，且其六个雷达维度不含 analyst；不能把 Catalyst 或 Sentiment 冒认分析师信号。price_date 有 44.37% 为空。导出没有 finished_at、in_universe 和源数据首次可得时间；24 个运行仅满足“全部 as_of 和 created_at 不晚于 D 收盘”的必要时间条件，**不是已证实在 D 收盘前发布**。主表回顾性关联、全臂完整样本、必要时间条件样本分别列出。旧因子/权重制度不能与 11-12 恢复预设的 v1.1.0 前瞻记录拼接。

统计复用冻结协议的 Newey–West，`L=max(h−1,floor(4*(n/100)^(2/9)))`。稀疏日期扩展保留实际日历距离，缺日残差贡献置零但分母是实际观测数，不把缺日当零收益。CI 为未校正的 1.96×HAC SE 描述区间；小样本不输出正式 p 值。HAC 有效 n 是方差设计效应近似；主要可分离决策量另报固定 offset0 的非重叠标签数，并保留全部 offset，不能取最优 offset。非重叠仍不保证独立。h=20 严重重叠，不凭几十条标签宣称几十次独立押注。

## Q3：三年面板的因子定义和期限

**已确认（实现）**：直接复用 baselines.py 的 uncached `_load_panel.__wrapped__()` + 临时路径覆盖模式，读取完整 v3 价格而非 504-session 截断面板；不改生产常量或缓存。XNYS 时间线核对完整。成员资格复用 loader 的 PIT CSV，PARA 身份另屏蔽；loader **没有应用 membership_updates.json**，故不声称幸存偏差已消除。CSV、manifest、updates 及输入 parquet SHA256 都保存到本地 JSON。

四个固定候选：R=真实 DSL 预设 `rank(ts_mean(returns,12))-rank(ts_std(returns,60))`（沿用原算子 tie 与缺值语义）；M=`close[D−21]/close[D−252]−1`；V=负的过去60-session日收益总体标准差（完整60个收益）；Q=最近已披露报表的 `gross_profit/assets`，assets>0，filing_date≤D，200自然日过期。Q 为季度报表比率，不冒称年度经典盈利因子的精确复现；日内发布时间、修订历史和财报 vintage 仍未知。

沿冻结 train / validation1 / validation2 / historical_test 日期，不拼块、不调起止、不借后块完成标签。训练仅核验实现，没有拟合参数；扩展训练前缀经 `purged_training_dates` 按每个 h 重做 purge，60 日另加 61-session embargo，详见 JSON。历史检查一律标 **not unseen**。未触碰 v1.1.0 的未来窗口。

IC 对每天可得因子与成熟标签求截面秩相关。收益以当时因子可评分的成员为 EW 控制，另存对 full eligible EW 的诊断，因此 Q 的可评分池缩窄不是“质量因子收益”本身。每个 D 锁定最高五分位、ticker 稳定打破并列；一名最多2%。

主收益估计固定 offset0，每 h 个 session 换仓，D+1执行；换手按新目标与上一期价格漂移后的权重计算，双边收费，初始建仓及分段末次统一退出都扣费。只在选中组与 EW 都完整时计算配对收益，缺失后在上一已知端点结束诊断段、下一完整段重建并重付建仓费。**这是一项分数权重的期限诊断，不是冻结控制组的月频/20%换手预算/整股现金重放**。其余 offset 与 10/15/20/30 成本全部输出；没有选最优 offset。
