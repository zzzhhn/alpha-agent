# 机器人账户：在原设计内精修与自然调度验收

## 边界与目标

保留 AlphaCore 页面壳、账户 tabs、TM 原子组件、深浅主题、现有账户和 BYOK。精修机器人账户的工作流、状态和信息密度，不换视觉身份，不修改投资参数，不强制交易。用户首先要能回答：机器人这轮做了什么、实际成交多少、现在持有什么、下次何时运行。

今晚自然调度观察独立于 UI 开发：不通过手动触发冒充自然成功，不在观察窗口中部署干扰执行。检查真实 run、LLM 响应、订单终态和 slot/action 幂等。

## 已观察到的问题与修复切片

| 问题 | 证据 | 精修方向 |
| --- | --- | --- |
| 左侧决策长文与动作列表推远持仓，右侧留白 | 生产首屏及已成交的 8 条动作 | 首页保留摘要与账本统计，明细进入现有抽屉；净值图不再堆在该左栏 |
| 入队记录不能反映完成状态 | schedule_observations 将所有真实 run 固定为 enqueued | 用真实 run 状态覆盖观察，仍区分计划与实际 |
| 当前估值与收盘区间收益容易混淆 | 生产当前 -0.13%，收盘区间 0.00%，两者截止时间不同 | 收盘区间时间前置，当前估值说明非实时，保留缺价状态 |
| 日期口径标注错误 | 订单 signal_date 是美东交易日，外围说明为 CST | 订单明确交易日，运行时间继续 CST |
| 订单抽屉缺基本事实、正常证据称错误 | 实际打开 GPN 成交详情 | 增加方向、数量、状态，拆开错误与撮合依据 |
| 已有长期持仓复核没有入口 | sim_bot_position_note 已保存，持仓表仅显示账户来源 | 只读 owner-scoped 查询当前持仓复核，明确不是建仓归因 |
| 查看来源运行时抽屉瞬间关闭后无反馈 | 当前 onRun 异步完成前未打开新 drawer | 即时显示加载和就地重试，保留请求版本隔离 |
| 刷新全页会清空已有事实，活动 run 与历史表不同步 | 当前 Resource 读取先置 null，poll 只更新 latest | 保留旧读数并标记刷新；同一 run 的多个视图同步 |
| 推荐已有驱动信息在模型输入中丢失 | 生产快照 ERIE 的 top_drivers 为 factor/analyst/rsrs，真实已持久化 context.drivers 为字符串空列表 | 修正 top_drivers/top_drags 字段映射，保留旧字段兼容；显式传递推荐原策略、期限和仅为信号名称的证据边界 |
| 切换服务商后仍沿用旧服务商的凭据提示 | 隔离组件中从 OpenAI 兼容接口切到 Kimi 后，仍提示已配置 | 新选择不继承旧凭据状态，提示确认对应 BYOK 与模型；不读取或改写密钥 |
| 保存失败提示可能在长配置正文的折叠区域下方 | 展开高级规则、清空两个唤起时段后，错误位于正文底端 | 错误放到固定操作底栏，在保存按钮旁始终可见 |

## 前后端契约

- run.order_summary 来自 sim_order，不从模型自然语言或 accepted 推断 filled。未知费用保留 null。
- `/bot/position-notes` 限当前 owner、bot、cohort 和最多 20 个非零持仓；不抓行情、不调用 LLM、不写库。保留源 run 和更新时间。
- scheduled observation 状态以对应真实 run 为准。派发和完成仍是不同事实。
- 推荐归因修复只改变后续 context 中原本遗漏的已有信息；不重写历史 context，不切换推荐策略，不修改用户持有期限或交易门槛。
- 维护空、失败、部分、加载、运行中与终态；不把不可用数据画成 0。

## 设计原则复核

| 原则 | 落点 |
| --- | --- |
| 意图对齐 | 首屏先看本轮动作、实际成交与自动计划 |
| 认知负担 | 首页短摘要，详细证据抽屉，表格有界 |
| 状态可见 | 刷新、来源读取、活动任务同屏同步 |
| 可恢复 | 抽屉内重试；不以重新唤起替代读取重试 |
| 可供性 | 持仓复核入口指向真实记录 |
| 设计服务任务 | 复用 TM，移除重复长文而非增加装饰 |
| 无需说明书 | 状态、时间与费用就近标注 |
| 尊重时间 | 只读按需查询，保留已有数据 |
| 不误导 | 意图、订单和持仓严格分开，未知不补零 |
| 单一主操作 | 立即唤起仍为唯一主操作 |
| 可追踪 | 订单与持仓复核可到源运行 |

## 横向约定与验收

新文案中英双语，沿用语义 token、tabular 数值、无位移淡入和 reduced-motion。保留 TmDrawer 焦点、Escape、焦点返回。验收真实长摘要、8 条动作、持仓复核、订单第二页、正常撮合证据、调度状态、口径与覆盖；保存配置、暂停、停止等会影响实盘观察的动作仅用隔离测试验证，不在生产盲点。
