# 今日推荐：定义、层级、时区、排名分、维度评级与返回

日期：2026-11-11。范围：路线图 PICKS-1～PICKS-6。原页原组件精修；不改融合权重、档位阈值、A–F 分段算法、价格新鲜度或交易门槛，不改写历史快照。

## 用户问题 → 行为变化

| 项 | 之前 | 之后 |
| --- | --- | --- |
| PICKS-1 评级变化 | 无定义，易与 A–F、涨跌混淆 | 标题旁可键盘聚焦的说明：同一股票在当前与上一份**同政策**快照各自 Top-50 中 BUY/OW/HOLD/UW/SELL 档位变化；不是 A–F、涨跌、盈利或指令。显示两份快照的交易所交易日；无上期不伪造（`current_market_date` / `prior_market_date` / `prior_generated_at`），上期查找跳过不同政策的 run |
| PICKS-2 层级 | 投资计划、理由复查、策略验证三个同款展开块把候选表挤到首屏下方 | 首屏：状态→变化→一行“研究记录”入口与较低权重的策略验证摘要→候选表；领先卡片移到候选表之后。研究记录为一个抽屉，内部分“全局投资约束”（原 profile API）与“逐股研究与复查”（原 notebook API），数据模型和历史不变；行内“记录”携带股票与快照/政策，仅在备注为空时作为可编辑默认值。策略跟随验证为独立对话框，缺失原因 + 重读，不显示伪 0% |
| PICKS-3 时区 | 手拼 `… UTC` | 共享格式化 + 本地偏好：本地（显示 IANA 名）/北京时间/纽约交易所（Intl `America/New_York`，含 DST）/UTC；SSR 与首帧固定 UTC 再切换，避免 hydration 差异；交易所交易日按字面显示，不做时区换算 |
| PICKS-4 排名分 | 只显示 σ 原值 | `rank_score` 0–100：同一不可变快照、同政策完整 eligible 集合的横截面百分位，升序平均秩，`ROUND_HALF_UP(100*(avg_rank-1)/(n-1))`；在方向/limit/分页之前计算；n<2 或缺值为空不补 0；高分偏多，做空榜不反转。搜索/非正式视图明确“不可用”，不对子集重算。`rank_score_method` 带版本 `xs_pct_avg_rank_v1`、n、run、sleeve 与定义；原 z 在提示里保留 |
| PICKS-5 A–F | 前端硬编码且写错（“F ≤−1.0σ”） | 后端 `grade_method`（`dimension_rez_v1`）为唯一来源：分段（F 严格低于最后切点）、维度成员、最少 20 观测、平坦阈值、缺失语义；表头图例对话框、逐芯片说明含真实分值；新快照带 `dimension_scores` 与缺失原因，旧快照明确“未记录分值”；全空维度在图例中说明而不是无说明消失 |
| PICKS-6 返回 | 小号按钮，不保留上下文 | 与“信号一致度”同基线高度的 secondary 返回；从推荐进入时恢复方向、策略、搜索、页码、每页数、主区与表格滚动；直接链接进入回到默认 |
