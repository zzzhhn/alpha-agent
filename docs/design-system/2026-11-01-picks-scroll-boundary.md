# 推荐页底端空白修复

## 原因

上一轮将每行重复窗口名改为 `sr-only` 读屏文本。其绝对定位没有被静态定位的 `TmTableFrame` 包含，向外延伸了文档滚动范围。推荐列表本身有滚动条，根文档又产生第二层滚动，所以内容结束后仍可下滑到空白。

线上复现：视口高度 875px，根文档滚动高度 3365px；main 高度 836px，内容高度 3403px。根文档可以滚动，而主区域不一定到达底端。该问题属于上一轮遗漏的底端交互回归。

## 最小修复

仅给既有 `TmTableFrame` 添加 `relative`，将绝对定位的 caption 和读屏标签约束在表格滚动容器内。没有删除读屏文本、限制列表高度、隐藏整页溢出或改变视觉布局。其他复用此表格框的页面也遵循相同定位规则。

## 验证

使用相同 50 条只读快照运行真实页面。修复后，根文档高度和滚动高度均为 875px，外层溢出为 0；main 仍为 836px / 3403px，完整列表保留。滚到底后再用滚轮连续下滑，main 保持底端，根文档 scrollTop=0，没有额外空白。末行 EXC 和辅助研究入口仍可见。

附加一个表格框回归测试，检查定位约束和读屏 caption/标签都保留。用户已授权修复、合并并生产部署；最终生产状态及截图记录在本次本地发布回执中，避免为发布记录再次触发构建。
