# 回测、选股与报告：原页精修

日期：2026-11-03。范围：`/backtest`、`/screener`、`/report`。

## 意图与边界

让研究者更快完成「配置研究、检查证据、比较与保留结果」。桌面优先，中文和英文均保留。继续使用现有米色／暗色 TM 工作台、侧边栏、字体、语义色和控件，不重建品牌或页面壳，不改回测算法、阈值和数据库。

线上观察：回测初始页有大幅空图表、重复未知数字及不可操作诊断占位；选股少量因子旁留大片空白，右侧控制项过长；报告十条历史示例占满首屏，表达式和生成操作位于下方。修正的是实际构图与操作路径，不是添加装饰。

## 实施

| 页面 | 保留 | 精修与必要行为修复 |
| --- | --- | --- |
| 回测 | 表达式、参数、单任务计算、验证门槛、比较、持仓 opt-in、历史及 Zoo | 稳定编辑区，成本摘要可见，五项空态门槛一致，移除多余占位；高级参数折叠后不可聚焦，运行时冻结；历史五条分页；草稿与旧结果区分；消除验证列最小宽度溢出 |
| 选股 | Zoo/prefill、组合方法、行业和市值过滤、API、CSV及完整结果统计 | 因子与组合区并列股票池；表达式换行，不强制 860px；因子五条／结果十条分页；键盘选择；行业中文显示但不改变底层值；失败和无结果不伪装为零；参数更改明确提示上次结果 |
| 报告 | 四类研究请求、比较、方向记忆、prefill、图表、打印与导出 | 编辑／生成首屏可见；来源库按需打开、全文检索、五条分页；历史示例只载入草稿；真实结果优先；参数快照、dirty draft 提示；HTML 导出与报告训练比例、分位数一致；诊断按钮回归内容流 |

不增加依赖、定时任务、数据库写入或默认每日持仓明细。报告仍需现有四类证据全部成功，未在本轮改变为部分报告。

## 实际页面证据

对比使用同一 Chrome tab、1710 × 875、中文浅色、同一三个默认 Zoo 因子、未运行状态；基线直接渲染当前 main 的原页面与组件，新版使用本分支代码。行业与股票池目录取自真实 API。没有生成假收益来填图。

已在会话内展示三组 `*-before-same-state-20261103.jpg` / `*-after-20261103.jpg`。本地图片存于本次会话的 visualizations 目录，不进入产品 bundle。

真实接口验证使用已保存的 Earnings Yield 表达式，手动触发，无 LLM 调用。报告实际返回 754 个交易日与样本外结果，界面保留过拟合风险，没有把历史示例的优良数据冒充本次表现。检查了草稿修改后的旧报告标记、来源库搜索／第二页、深度分析窗口与焦点返回、英文暗色。此次验证不代表模型盈利能力验收。

真实回测结果与选股请求也已完成。选股返回 20 条，验证第一条详情及第二页 11–20 条，翻页后旧详情关闭、统计仍使用全量。1440px 桌面下主区域没有横向溢出。回测结果检查发现旧图表说明误写为美元轴／绿色超额曲线，本轮纠正为实际归一化净值和回撤轴，并中文化图例；固定样本的 Walk-forward 空态改为明确恢复步骤。

## 11 条原则复核

| 原则 | 本次落点 |
| --- | --- |
| 意图对齐 | 配置旁保留 Run／Generate；来源选择只载入草稿 |
| 认知负担 | 去除重复占位、展开式长示例和过长结果列表 |
| 状态可见 | `BacktestVerdictBar`、Screener DecisionStrip、Report dirty snapshot |
| 容错 | 保留输入与成功结果，明确失败可重试，不删除研究历史 |
| 可操作性 | 折叠控件移出 DOM；库、分页、详情都有明确语义 |
| 设计隐形 | 既有 TM 壳与组件，没有新导航或品牌 |
| 无需说明书 | 首屏呈现因子输入、参数与下一步动作 |
| 尊重时间 | 不加载额外持仓明细，不因选择示例立即计算；分页限制首屏内容 |
| 不撒谎 | 未评估不等于通过，无结果不等于零；真实结果不混入历史示例表现 |
| 一个主动作 | 每页唯一绿色运行／生成按钮，其余为次要操作 |
| 可追踪性 | 结果与运行配置快照绑定，比较和导出不混入未运行草稿 |

## Cross-cutting conventions audit

复用 `WorkbenchHeader`、TM 输入、按钮、表格、分页和对话框，页面本地 CSS 只修复数字控件的重复边框。不改变侧边栏。所有新增说明提供中英两种文本，专业缩写继续遵循既有词汇体系；行业值在 API／CSV 中不翻译。字体不低于 12px，已有主题 tokens 与 reduced-motion 约定不变。未添加位移动画。

TypeScript 检查、53 项聚焦测试、现有设计语言审计及 56 对 token 对比度检查通过。构建与部署由本次 PR 的 CI／Vercel 执行；实际生产回读记录与截图在会话交付中提供。视觉满意度仍由用户判断，不能由测试通过代替。打印保留层已做组件检查，本轮没有创建新的 PDF 文件。
