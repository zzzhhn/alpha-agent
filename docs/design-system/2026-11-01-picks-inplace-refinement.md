# 今日推荐：原页面内精修

日期：2026-11-01。状态：已实现、已本地浏览器验证；未推送部署，视觉验收待用户反馈。

## 范围与判断

用户要求从现有「今日推荐」页面开始，保留已有设计和组件，提供同页前后对比。上轮独立重构方案已被否决，不作为本轮基线。

本轮按 integrate-design 的「保留身份、精修现有页面」方式实施：保留 AlphaCore 顶栏与侧栏、暖灰绿浅色及原深色主题、衬线标题、等宽数字、TM 矩形面板、三张模型领先卡片和完整候选表。没有替换品牌、导航、页面类型、依赖或后端接口。

目标是让用户更快看到候选、比较已有数据，同时仍能找到投资计划、研究记录及收益证据。

## 实际改动

| 部分 | 改动及保留内容 |
| --- | --- |
| 首屏 | 简化重复说明，详细定义放入「统计口径」。保留「排名不是交易指令，HOLD 表示观望」。 |
| 投资计划、研究记录 | 复用原组件，新增仅在推荐页启用的 compact 变体。收起时按钮在标题行，展开仍为原表单和操作。其他调用者默认布局不变。 |
| 策略跟随验证 | 默认显示一行真实状态，展开仍可查看成本、基准、窗口、净值和缺测信息。缺数据不显示为零，错误、隔离、版本不匹配等状态不被隐藏。收起不挂载图表。 |
| 模型领先 | 保留原三卡结构，仅整理内边距、行距和留白。 |
| 候选表 | 保留全部字段及 50 行。四个统计窗口名放到表头，不在每行重复；保留数值、样本量、缺失和风险提示，读屏文本仍有窗口名称。关键数值使用既有 14px 字号。 |
| 工具栏 | 搜索与刷新对齐，增加清除搜索，辅助研究指标移至候选表之后。 |
| 加载与失败 | 新筛选未返回时标明仍是上次结果，暂停模拟按钮；请求失败保留旧结果及重试入口。清除空搜索期间显示加载，不再错误声称任务没有运行。 |
| 排版修复 | 推荐页的纵向子区块禁止被 flex 压缩，修复较窄桌面下顶部控件遮挡，以及失败提示覆盖筛选控件。未修改全局布局。 |
| 账户现金 | 原页面将现金固定传为 0；现复用原账户读取结果的 available_cash，未取得时传未定义，由原表单读取，不伪装成余额为零。未改变交易 API。 |

## 验证与边界

- TypeScript 检查通过；2 个针对性测试文件共 7 项通过；design-system audit 通过。
- 浏览器检查了中文和英文、深浅主题、默认桌面和 1280px 宽桌面，以及说明展开、证据展开、表单入口、键盘操作、空搜索、清除搜索、失败后恢复。
- 预览代理固定公开 GET 响应，所有写请求均阻断。候选搜索检查在固定 50 条数据中进行；另一个策略的失败由代理刻意返回，用于检验恢复流程，不是对生产接口故障的诊断。
- 未执行生产刷新、保存私人记录、模拟下单、数据库迁移或 LLM 调用。登录后保存和真实交易 API 不在本轮验证范围。
- 截图仍显示真实的「部分数据待恢复」和「暂无可比收益」。本轮 UI 改善不代表这些后端数据问题已解决，更不构成策略盈利证明。
- 实现保存在 `codex/alpha-picks-inplace-refinement` 隔离工作树，main 未改动。临时浏览器标签及两个预览服务已关闭，截图保留供本轮验收；用户确认无需历史对比后才考虑清理。
