# 持续机器人模拟仓：交付与运行说明

## 本轮范围

在原模拟仓内增加人类／机器人账户切换，保留既有人工交易入口与账本。
机器人使用用户已有 BYOK，支持手动唤起及按美股交易日历定时运行。
这是模拟实验，不连接券商，不承诺盈利。

实现由一个独立前端 session、账户与撮合 subagent、估值 subagent 和主 session 分工完成。
integrate-design 用于保留现有 TM 组件、双栏工作区、抽屉和分页，仅使用淡入，不另建视觉体系。

## 使用路径

1. 打开“模拟仓”，选择“机器人账户”，创建独立账户；虚拟初始资金与人类账户互不转移。
2. 选择已保存的 BYOK provider/model，填写策略说明，保存。模型密钥只在后端解密，不传 GitHub runner。
3. 点击“立即唤起”。关闭页面不影响任务；运行历史可查看模型用量、决策摘要与动作结果。
4. 不交易也是有效结论。受理、等待分钟行情、成交是不同状态，最终结果以订单账本为准。
5. 想自动运行时启用定时，可独立选择开盘后 30 分钟、收盘前 30 分钟。暂停定时不清仓，仍能手动唤起；停止本轮只停止后续决策，不回滚已成交或抹去已受理订单。

默认每日最多 6 轮、每轮最多 3 次模型调用机会，最多 8 个持仓，单标的目标权重不超过 25%。
额度包含手动与定时运行；模型自己的内部重试可能产生额外计费，记录仅能展示上游实际返回的 token 用量。

## 数据与执行边界

- V049 将旧账户明确归为 human，新增 user/kind 唯一约束；V050 增加 bot 配置、运行、标的与订单证据。
- 人类账户继续使用既有 daily_close_v1；bot 使用 intraday_next_bar_v1，原始未复权分钟 bar 的开始必须晚于订单受理，bar 完整后才能确认成交。
- 默认实验假设为 5 bps 不利滑点、10 bps 费用，可配置。买单只使用已结算现金，不能先花尚未卖出的仓位所得。
- 不全市场抓取或保存分钟 bars。每次仅有界获取研究候选／持仓行情，持久化最新 mark、必要成交证据和每日净值。
- NAV／收益缺少可靠价格时返回 null；曲线断开而非补零。公司行动或已知代码身份冲突阻止相关撮合，不把旧 PARA 擅自换成其他股票。
- 同一账号只有一个活动 run；account → run → config 锁顺序、lease fencing 和 `(run_id, action_id)` 唯一键防止重复执行。
- 数据库新运行沿用容量准入门槛；轮询接口不读取大 context。详细 context 最大 64 KB。没有清理或删除现有历史。
- 内置 JSON 工具协议已落地；首版不发行外部机器人密钥，外部接入仍是预留项。

## 调度与部署

GitHub `paper-bot-runner` 只携带已有 CRON_SECRET，后端阶段化执行。单模型调用 250 秒，函数上限显式 300 秒；采集、模型、执行、估值分别调用，不把全部塞进一次请求。
定时使用 America/New_York 的少量唤起窗口，再由 NYSE 日历判断到期与半日市，允许 20 分钟迟到，不在盘外补交易。
GitHub 调度不是精确定时保证；错过窗口时不会假装执行成功。

依据：[GitHub 时区与调度](https://docs.github.com/en/actions/reference/workflows-and-actions/workflow-syntax)、[Vercel 函数时限](https://vercel.com/docs/functions/configuring-functions/duration)。

发布顺序：本地迁移与账本验证 → 提交 feature → 应用 V049/V050 → 合并主分支部署 → 线上账户、BYOK 与行情 smoke。
回退时停 bot 调度与入口，保留账本；不能直接回退到假设每 user 只有一条 sim_account 的旧代码。

## 已有验证

- 本地 PostgreSQL：旧 human ID、余额、持仓、净值不变；新 bot 独立；真实 SQL 接受、成交及重复结算验证通过。
- 本地 API／BYOK adapter：读取所选 provider/model、服务器解密、决策持久化、闭市不交易、跨用户 404、同 slot 去重、停止任务通过。此处模型响应为受控测试响应，不冒充真实线上 LLM。
- 本轮相关 Python focused 检查 106 passed、2 个显式真实 DB 测试默认跳过；两项真实 DB 测试已另行运行。
- 前端生产 build、设计系统审计、TypeScript、相关 10 项 smoke 通过。
- 发布前只读生产基线：1 个人类账户，现金合计 1,000,000；无订单、持仓、净值行；数据库约 238.3 MiB。
- 线上验证结果在部署后追加。此前本机单次 Yahoo 分钟行情探针遇到限流，不代表生产可用；必须单独验证，不用日线替代证明。

后续观察至少覆盖几个实际交易日：分钟报价覆盖率、调度迟到、实际模型耗时、净值连续性、费用后收益与 SPY 对照。不能据单次 smoke 宣称长期稳定或赚钱。
