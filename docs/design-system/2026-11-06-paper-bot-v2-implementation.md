# 机器人账户 v2：实现与验收

## 本次落地

保留原 TM 工作台、人类／机器人双账户、现有 BYOK 和撮合账本，不引入常驻服务、全市场分钟行情、向量库或新的模型服务。

- 当前运行准入与历史决策分开：盘外、接近收盘、额度不足、账户／凭据异常给出明确状态。暂停定时不阻止符合条件的手动唤起。
- 每次完整模型调用仍允许 250 秒；启动前保留 180 秒执行余量。盘外不付费调用交易模型，补查不透支执行窗口。
- 显式 `patch_targets`，未提及的持仓不自动清空。空 rebalance 无效；增加仓位必须引用该标的可用研究证据，减仓可引用持仓事实。
- 策略增加持有期、研究最大年龄、最小调整幅度和双边换手预算。新增默认值为 20 个交易日／3 个交易日／0／200%，保留已有显式配置与旧参数。
- 研究包仍限 Top 20 加持仓，加入交易日年龄、前次评级／排名、最近三轮简短决策、结构化持仓笔记。行情、context 和模型调用均有界。
- 订单详情从订单表回读实际终态，不能把 accepted 显示为 filled。主屏最多四条动作，完整理由与原始结果只在抽屉中展开。
- 新增只读表现接口，报告成本后 NAV、现金暴露、同日期 SPY 价格参考、成交／到期计数、已知费用与最近 20 轮 token。参见[指标契约](./2026-11-06-bot-analytics-contract.md)。缺失值不记为零。
- 新增轻量计划时段记录及阶段计时。已入队时段不会重复入队；过期时段显示 missed，而非将工作流成功解释为机器人已执行。

## 发布顺序

先应用 additive `V051__paper_bot_diagnostics`，再发布后端和前端。迁移只增加诊断字段、索引和计划时段表，不修改旧现金、持仓、凭据或计划开关。计划恢复属于单独、经用户授权的运行操作。

公开代码与验证说明不包含个人策略文本、账户 ID、运行原文、凭据或数据库连接串。实际账户验收截图、运行回执留在本地私有交付目录。

## 已完成的工程验证

- 定向模型／预算／证据／交易／指标测试。
- 隔离本地 PostgreSQL 的真实迁移、幂等订单、成交与费用记账，验证人类账户现金／持仓／历史记录不变。
- 本地 SQL + owner API + 加密测试凭据 + 替代模型适配器，验证持久阶段、诊断回读、指标接口、调度唯一性。此测试不代表真实 BYOK 或市场报价验证。
- 前端状态与动作契约 7 项、TypeScript、既有设计系统审计。静态检查不替代下表的浏览器验收。

## 明确未宣称完成

- GitHub 定时任务不是精确定时 SLA；载体迟到超过 20 分钟会被记录为漏过时段。需要真实时段观察，不能靠本地测试承诺零漏跑。
- 五个交易日的稳定性观察、二十个交易日的投资能力评估，必须等待相应真实记录。
- 同约束、同撮合的确定性组合尚未建立有效前向实验账本。当前 SPY 是价格参考，不是含股息和交易费用的模拟投资对照，不能称为完整投资实验已结束。
- 没有自动补齐分红／公司行动、推算缺失历史净值或强制买入。P2 的行情服务替换、调度载体迁移和详细 context 清理，先依据观测瓶颈和保留政策，不在本次擅自增加订阅或删除历史。
