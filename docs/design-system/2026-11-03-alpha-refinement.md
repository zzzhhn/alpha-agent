# 因子 Alpha 原页精修

状态：本机页面检查完成，用户于 2026-11-03 审阅后授权合并部署。下述为本地证据；最终生产状态另见本轮发布回执。

## 目标与边界

用户任务：写出一个研究假设，设置验证条件，查看表达式与反证，再决定重测或进一步比较。桌面优先，同时保留窄屏可访问性。

- 保留：原有暖纸色／深色主题、字体、导航、TM 控件、研究链路与三个证据面板。
- 精修：输入与参数的分区、动作层级、初始状态密度、字段中文与键盘恢复。
- 不替换：页面类型、全局设计语言、数据源、LLM、回测算法及门槛。

## 改动

1. `HypothesisInputCard`：左侧写假设、浏览示例／历史及启动；右侧六项验证参数，避免输入、动作、参数挤成两行。中文显示“多空／只做多／只做空／不中性化／行业中性”，提交值保持不变。
2. 生成表达式前不展示无法使用的重测按钮，生成后继续提供参数重测。运行中冻结输入、示例和参数，避免界面条件与当前请求不一致。
3. `VerdictBar`：空闲状态压缩为简洁状态带，指标保留“—”；运行／结果状态保留原有详细数据与门槛。
4. `EvidencePaneGrid`：未运行面板最小高度由 260px 改为 144px，去除内部重复虚线盒；加载、错误、真实结果仍保留各自呈现。不伪造结果或 loading。
5. `AlphaExperimentLedger`：标题层级统一，空态缩短；已有记录仍保留前五条，窄屏时表格在自身区域横向滚动。
6. 历史弹层支持 Esc 关闭并返回触发器焦点；参数数字框去掉重复内框，保留聚焦提示。

没有增加请求、轮询、依赖或数据库写入，也不改变生产数据与已有浏览器历史。

## 原则复查

| 原则 | 具体落实 |
| --- | --- |
| 意图对齐 | HypothesisInputCard 的输入、示例和主操作集中 |
| 降低认知负担 | 独立参数区；未运行证据区紧凑呈现 |
| 状态可见 | 继续使用 useAlphaChain 的加载、失败、完成状态 |
| 可恢复 | 历史 Esc 回焦点；原重试与重测保留 |
| 可操作性 | 沿用 TmButton、TmField、TmDialog；空输入不能提交 |
| 设计服务任务 | 不换导航、风格或页面类型 |
| 易理解 | 参数中文化；示例入口靠近输入 |
| 尊重时间 | 减少首屏空白和无效动作，不增加网络请求 |
| 不撒谎 | 未运行显示破折号，绝不填入示意绩效 |
| 明确主操作 | “翻译并回测”为输入区唯一实心主按钮 |
| 可追踪性 | 保留最近实验、表达式及现有来源诊断 |

## 跨页面约定

复用 WorkbenchHeader、TmScreen、原侧栏及当前 locale 分支约定；只使用 TM tokens 和已注册图标。新增布局 CSS 局限于 Alpha 页，证据内容不改。无全局控件样式迁移。

- 本地预览渲染实际页面、共享组件与生产字体，不是图片原型。会话／健康状态使用本地适配，研究 API 被隔离，不调用付费 LLM 或生产数据库。
- 同一初始状态、相同研究文本、相同参数、同一 1710×930 视窗对比。两版使用相同的空浏览器历史；没有删除线上浏览器历史。
- 示例选择同时加载假设与中性化参数，历史弹层／Esc、输入启用主按钮、中文／英文和深浅主题已检查。
