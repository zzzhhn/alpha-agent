# Alpha Agent 全站交互审查与修复

日期：2026-11-05 至 2026-11-06。主代理负责整合与实现，三名 GPT-6.1 Sol（high）独立审查。沿用 integrate-design 与现有 TM 工作台，不改品牌、页面骨架或现有账户数据。

## 审查方式

三组分别覆盖日常工作流、研究工作流、高级研究与参考页面。先从生产页面点击真实控件，再回溯代码；同类数据行按控件与状态抽样，不把每条记录都算一次通过。受本机资源限制，同一 Chrome 实例内一次只用一个任务标签，交接后关闭任务标签，保留用户原有窗口。

可安全操作的下拉框、抽屉、弹窗、分页、搜索、折叠、键盘导航均纳入清单。交易、LLM、挖矿、报告计算、凭据保存、审批及删除不为测试而执行。无现成结果导致不可达的控制，和实际操作后通过的控制，分开记录。**这不是“每一个按钮都已通过”的声明。**

分组原始证据：[日常审查](daily-review.md)、[研究审查](research-review.md)、[高级审查](advanced-review.md)。对应 JSON 记录每组具体步骤、状态与缺口。主代理的修复验收另行记录，不覆盖生产基线证据。

原始基线合计 235 组：143 通过、13 失败、79 受阻。失败条目不是独立缺陷数量，受阻包含计算／写入边界、缺失结果状态及尚未点开的安全分支。主代理另行补验报告关闭按钮、回测高级数字与股票池、Screener 滑块键盘路径；不改写原审查员的观察。

## 实现边界

- 无数据库迁移、数据删除、账户调整、模型替换或凭据更新。
- 未增加动画库、UI 框架或生产依赖；保留既有字级、配色、密度、页面分区。
- 不把缺失收益、缺失检查或未验证参数包装成成功。没有新增“预计收益”或收益保证。
- 数值字段的键盘焦点已实测可见，最初源码疑点撤回，不重复叠加样式。
- BRAIN 历史接口本就支持用户隔离和分页，本轮仅补齐客户端入口，不进行行情回补或挖矿。

### 主代理修复版交互复验

Vercel 预览 READY，但本机访问其随机预览域名发生 TLS 连接失败，没有绕过证书保护。主代理改用独立本地前端 `127.0.0.1:3106` 验证同一源码；没有复制生产登录凭据，使用临时本地开发配置，未触发模型或计算。

- Report：成本 -1 出现中文字段错误，生成禁用；打开来源菜单后 Escape 保留父对话框，关闭按钮返回入口；Tab 关闭菜单并回到表单顺序。
- Backtest：top=99、bottom=0、lookback=2000、cost=-1 均显示对应错误、运行禁用；重置恢复；唯一股票池选项可操作。
- Screener：252 日预设、原生滑块值和 End 均为 252；推荐数 End 可到 100，之后恢复原 20 与 60 日。1440×760 与默认桌面视口下菜单贴合按钮，间隔 4px，无根节点水平溢出。
- 源码交叉复核发现的跨页旧账本快照已取消，避免刷新结果却保留旧漏斗状态。

截图位于本机 `sidebar-audit-fixed` 目录。后续生产复核与发布动态状态记录在本次 PR 和会话回报中。

### 审查意外与边界

高级组误把 Zoo 的回测交接判成只载入草稿，实际触发了一次 Earnings Yield 示例回测，也更新了本浏览器的最近表单记忆。没有下单、生成研报、调用 LLM 或修改 BYOK；未确认服务端计算最终完成状态。该事件在高级组报告完整记录，不能把本轮写成“零副作用”。原设计的自动执行行为未被偷偷移除，本轮先让入口文案明确。

Settings 在修复前主动未进入，避免挂载覆盖远端关注列表。最终验收不保存 key、不测试付费连接、不新增关注股票、不执行迁移或审批。无现成结果的操作仍需在具备真实结果的专门验收中完成，不能用此审查宣称端到端功能已全部通过。
