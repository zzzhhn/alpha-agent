# 重大事件、换手与独立影子实验

目标是区分漏报、迟到、看见但不该交易，以及真正可以在常规时段捕获的收益。事件库、影子账本和私人期权缓存不属于用户模拟账户。读取这些页面不会唤起模型、下单或触发采集。

## 从页面开始

| 想弄清的问题 | 入口与读法 |
| --- | --- |
| 今天的公告有没有收到？ | 警报 → 重大事件与来源覆盖。按代码筛选；即使列表为空也要看对应来源状态。公布日不一定有精确时刻；首次收到才是平台观察证据。 |
| 当时机器人有没有看到？ | 模拟仓 → 机器人账户 → 运行详情 → 证据。实际输入的事件 ID 与当时影子库留存的公告分列。旧运行不回填。 |
| 换股是否值得？ | 机器人账户 → 换手归因。实际、原仓不动、仅减仓使用同一起始账户；“仅减仓”只复用实际卖出且不超过原仓，不声称每笔卖出都有风控理由。相对持有贡献已含成交费，不再减一次滑点。缺期末标价时，不能用实际净值推算反事实净值。 |
| 空头有没有带来价值？ | 私人股票事件影子账户：对照同一政策、同一批事件的现金、仅多、多空三个账本。只对有明确方向依据的事件做反应；缺借券、费用或合格报价时保留原因，不假设“零成本可借”。原机器人持仓不同，**不能直接相减两个账户的美元盈亏并称为事件 alpha**。 |
| 免费期权行情能做什么？ | 管理员机器人页 → 私人期权观察。只采 SPY、QQQ、NVDA 两周内最近两个非当日到期日，每侧最多三个近价行权价。缺时标、OI、Greeks 或费率不补值。报价为派生指示价，不是 OPRA BBO、不用于撮合或模型输入。 |

11 月案例的两次公告见 [NVDA 时间线](../research/2026-11-24-nvda-event-evidence.md)。它检验信息到达链路，不用来选择策略参数。

## 发布与资源

1. 先在隔离数据库验证 V055 至 V061，再迁移生产并发布 API 与前端。新表是独立实验表，不需修改 BYOK、用户账户余额、订单或旧净值。采集、影子模拟和行情订阅使用不同的入口。V061 只存经完整行情复核的账户级衍生汇总，不公开逐笔行情与持仓。
2. 事件 tick 复用已鉴权调度与来源限额，详见 [Vercel 调度](vercel-cron-ticks.md)。关注来源级最后成功时间、403/429、不可用、优先池轮换与 SEC/IR 覆盖差异，不只看 HTTP 200。
3. 将 `EVENT_SHADOW_ENABLED=true` 用于启用独立前向观察。每个固定时段请求 `/api/cron/event-shadow`；不回放激活前的订单。盘前公告可记录，交易模拟不使用非正规时段行情。没有有效借券证据及成本时，即使方向看空也不能填单。
4. 期权默认关闭。在许可范围内的私人环境设 `PRIVATE_OPTION_RESEARCH=true` 并通过已有秘密管理提供 `ALPACA_API_KEY`、`ALPACA_API_SECRET`。**无需复制本机凭据到托管环境**。只用固定 HTTPS GET、IEX 和免费 indicative 源，不使用下单端点。每半小时共享采一次，数据库保留 30 日，浏览器读缓存而不触发新请求。免去订阅费不等于原始行情可以公开分发。
5. 使用同一机器的只读采样命令：项目根目录运行 `PYTHONPATH=. .venv/bin/python scripts/research/observe_option_chain.py NVDA`。它不写 DB、不修改配置。供应商资格不足时报状态，不自动购买或升级。
6. 暂停股票影子或私人期权时关闭相应开关。保留既有实验数据用于审计，旧账户继续照原方式运行；不自动重置、补单或重算账本。

借券数据不可用时不开空，不把 easy-to-borrow 标签解读为免息借券。已有经许可的真实借券回执时，操作员可以将脱敏 JSON（`ticker,source,evidence_id,source_at,valid_until,status,available_shares,annual_rate`，年费率使用小数）通过 `scripts/research/import_shadow_borrow.py` 导入 V060 私有表，只对数据库实际收到之后的试验有效。历史回执不会变成当时可成交的证明。不要提交凭证、账户信息或原始回执到 Git。

## 如何评审

- 在快收盘的常规时段保留每个影子账本的抽样记录。它不是官方收盘价。无法可靠标记的持仓不计作现金或零；缺日／标价不全的窗口不展示整段收益和最大回撤。已结费用和成交名义额可单列。
- 至少 20 个可比交易日、30 个有交易且三组结局可比的独立事件后做第一次人工评审。同一发行人的同交易日最多计一次。报告成本、成交覆盖、最差事件、回撤与缺口；这是最低观察量，不是统计显著性，也不是转入旧机器人账户的授权。
- 免费数据官方说明：[Alpaca 期权源](https://docs.alpaca.markets/us/docs/historical-option-data)、[合约身份](https://docs.alpaca.markets/us/reference/get-options-contracts)、[指示快照](https://docs.alpaca.markets/us/reference/optionchain)。SEC 接口是披露来源而非保证零延迟的新闻交易服务：[EDGAR 数据 API](https://www.sec.gov/search-filings/edgar-application-programming-interfaces)。
