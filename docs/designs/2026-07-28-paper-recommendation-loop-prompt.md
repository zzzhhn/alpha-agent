Use case: ui-mockup
Asset type: production-ready desktop web application design anchor for AlphaCore paper trading
Primary request: Design a single unified paper-trading workspace whose visible user journey is 今日推荐 → 查看价格 → 一键跟单 → 持仓验证 → 归因回看. This is not a generic brokerage dashboard. It is the action arm of a daily stock recommendation system.
Canvas: 1536 × 1024 desktop viewport, full-page screenshot, no device frame.
Style: dense professional quantitative terminal, dark near-black background, sharp rectangular geometry, thin low-contrast borders, compact spacing, monospaced numeric typography, restrained off-white text, one electric green accent for positive state and primary action, muted red for losses. No gradients, no glassmorphism, no oversized rounded cards, no giant empty regions.
Header: compact title “模拟仓” with one persistent disclosure “日频数据 · 市价单按下一交易日收盘价成交”. Show account equity, available cash, total return, and recommendation-attributed return as small aligned metrics, not isolated cards.
Main composition: one coherent grid with three connected areas, visually linked by alignment and shared selection state.
Area 1, primary workflow: a dense table titled “今日推荐” listing AAPL, NVDA, MSFT. Each row visibly includes company name, ticker, recommendation direction, latest available price, daily change, confidence, short rationale, and one clear button “跟单”. The selected recommendation row is AAPL.
Area 2, contextual order ticket beside the selected recommendation: heading “跟单 AAPL”, show recommendation date and latest price, BUY/SELL segmented control, MARKET/LIMIT segmented control, quantity, estimated cost, available cash, and one dominant green action “提交模拟单”. Never require the user to guess a ticker. Include a small recovery affordance to clear the selection.
Area 3, validation loop below: holdings table with ticker, current value, unrealized P&L, source chip “今日推荐 07-28” or “自主交易”, and contribution to recommendation performance. Adjacent compact attribution panel compares “跟单收益” and “自主交易收益”, with a small equity curve and benchmark line. Make causality honest by using labels like “同期记录” and “归因来源”, not speculative explanations.
Navigation: retain AlphaCore platform shell with a narrow left sidebar. “今日推荐” and “模拟仓” sit in the same DECISIONS group, and “模拟仓” is active. The content must feel native to a research terminal, not a consumer trading app.
Hierarchy: the recommendation table and selected contextual ticket form one dominant primary task. Holdings and attribution are secondary evidence. At most one filled primary button is visible in the active context.
Text to render verbatim where practical: “模拟仓”, “今日推荐”, “跟单 AAPL”, “提交模拟单”, “持仓与归因”, “跟单收益”, “自主交易收益”, “日频数据 · 市价单按下一交易日收盘价成交”.
Constraints: production-feasible UI, information-dense but readable, consistent 8px spacing rhythm, no four disconnected tabs, no manual ticker text box as primary flow, no large blank areas, no fake real-time claims, no stock photography, no people, no phone mockup, no watermark, no extra logo.
